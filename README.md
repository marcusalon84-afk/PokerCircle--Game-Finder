# PokerCircle — Game Finder (pokercircleIL.com)

פלטפורמת אינטרנט מתקדמת בעברית (RTL) לאיתור וגילוי טורנירי פוקר חיים בישראל ומועדוני אונליין ב־ClubGG, תוך הקפדה מחמירה על **שקיפות מחירים מלאה** ואיסור על עמלות נסתרות.

---

## ערך הליבה של המוצר
> **״מוצאים טורניר. יודעים על מה משלמים.״**
> כל טורניר מפרט בבירור: סכום לפרסים + עמלת מארגן / בית + תשלום חובה נוסף (עם הסבר).

---

## יכולות המערכת בגרסה זו

1. **לוח טורנירים חיים בישראל**:
   - סינון חופשי לפי עיר, מארגן ושם אירוע.
   - סינון מועדים: היום, 7 ימים קרובים, כל המועדים.
   - סינון אזור / עיר (תל אביב, הרצליה והשרון, מרכז, ראשל״צ והשפלה, ירושלים, צפון, דרום).
   - סינון לפי **סך הכל כניסה לתשלום** (חישוב אמיתי הכולל עמלות ותשלומי חובה).
   - חישוב מרחק משוער למרכז העיר בלבד ("השתמש במיקום שלי") עם הסבר שהכתובת המלאה תימסר ע״י המארגן.
   - מיון לפי מועד קרוב, מחיר נמוך, או מרחק.
   - מנגנון תוקף פרסום (עד 7 ימים או תום האירוע). אירועים שפגו מוסרים אוטומטית מהחיפוש.
2. **קטגוריית מועדוני אונליין ב־ClubGG**:
   - מופרדת לחלוטין מלוח הטורנירים החיים.
   - אזור הדגל: **מועדון PokerCircle ב־ClubGG** (מספר מועדון: `822466`).
   - הצגת הרשמה מוקדמת ויעד השקה (50 שחקנים) לקראת טורנירים בלבד (ללא קאש).
   - הפניה לטופס ההרשמה ב־Google Forms.
3. **שקיפות מחירים מובנית**:
   - הפרדה מוחלטת בין פרסים, עמלת בית ותשלומי חובה נוספים.
   - הצגת הנוסחה ישירות בכרטיס האירוע ובחלון הפרטים.
4. **עמודי פרופיל מארגנים ודירוגים**:
   - פרופיל קבוע למארגן הכולל דרכי התקשרות, אירועים פעילים ודירוג ממוצע.
   - מנגנון ביקורות: כל ביקורת חדשה נכנסת למצב `pending` וממתינה לאישור מנהל.
   - הגבלה של ביקורת אחת לכל משתמש על מארגן למניעת ספאם.
5. **ממשק ניהול מאובטח (Admin Portal)**:

   - פעולות מתקדמות: ערוך, הסתר/הצג, שכפל כטיוטה חדשה, וחדש פרסום ל-7 ימים נוספים.

   - מעקב מדדים בסיסי (לחיצות WhatsApp, טלגרם, טופס הרשמה).

## התקנה והרצה מקומית

```bash

# הרצת שרת פיתוח מלא (Express + Vite בפורט 3000)
npm run dev
```

פתח את הדפדפן בכתובת: `http://localhost:3000`.

## פריסה ב־Hostinger

הפרויקט נבנה מראש במבנה מלא המתאים לפריסה ב־Hostinger (ב־Node.js / VPS / Cloud) או בשילוב Hostinger עם מסד נתונים Supabase / PostgreSQL:

### אפשרות א': פריסה כ־Full-Stack ב־Hostinger VPS / Node.js
1. העלה את קוד הפרויקט לשרת ה־VPS ב־Hostinger.
2. הגדר את משתני הסביבה לפי `.env.example`.
3. הרץ בנייה:
   ```bash
   npm install
   npm run build
   ```
4. הפעל את השרת באמצעות PM2:
   ```bash
   pm2 start "npm run start" --name pokercircle
   ```
5. הגדר Nginx Reverse Proxy להעברת תעבורה מדומיין `pokercircleIL.com` לפורט 3000 עם תעודת SSL של Let's Encrypt.

### אפשרות ב': חיבור למסד נתונים PostgreSQL / Supabase
1. פתח פרויקט ב־Supabase או מסד PostgreSQL ב־Hostinger.
2. הרץ את סקריפט המיגרציה הנמצא בתיקייה: `migrations/001_initial_schema.sql`.
3. הגדר את משתנה `DATABASE_URL` בסביבת הייצור.
